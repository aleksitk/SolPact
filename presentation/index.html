SolPact

Put your SOL where your goals are.

A commitment app on Solana: stake SOL against a goal, check in daily on-chain, and reclaim your stake — or forfeit it if you break the streak. Built with Cursor · Cursor Track + Superteam Georgia / Solana.

The Problem

Keeping promises to yourself is hard — and breaking a habit streak costs you nothing.

Habit trackers show a streak, but there's no real consequence to quitting. No skin in the game means it's easy to give up.

The Solution

Add a real cost to your commitments

🎯
Commit Set a goal + stake SOL for N days
🔒
Stake SOL locked in the vault
✅
Check in Daily on-chain memo
🏆
Reclaim Finish → get it back

Solana's near-zero fees make daily micro check-ins actually practical — this wouldn't work economically on most other chains.

How Solana & Cursor are used

Solana

Phantom via wallet-adapter · @solana/web3.js · System Program transfers for stake & claim · SPL Memo for daily check-ins · Explorer links on every action. No custom program needed for the MVP.

Cursor

Scaffolded the app, wrote the wallet integration & transaction logic, built the UI and check-in / claim flows, generated integration tests, and cleaned up dependencies + cross-platform install issues.

React + Vite + TypeScript Tailwind CSS v4 @solana/web3.js wallet-adapter (Phantom) Devnet only
